Requisitos hardware

Funciones del sistema operativo

El sistema operativo es el conjunto de programas que gestiona los recursos del equipo y actúa de intermediario entre el hardware y las aplicaciones.

  • —Gestión del procesador y la memoria
  • —Gestión de dispositivos de entrada y salida
  • —Gestión del sistema de archivos

Concepto clave

Partición

División lógica de un disco físico que el sistema operativo trata como una unidad de almacenamiento independiente. Cada partición puede tener su propio sistema de archivos.

Un mismo disco puede contener varias particiones con distintos sistemas operativos.

Proceso de instalación

Instalación limpia frente a actualización

Instalación limpia

  • ●Elimina todos los datos del disco
  • ●Sistema sin errores heredados
  • ●Requiere reinstalar aplicaciones

Actualización

  • ●Conserva archivos y programas
  • ●Puede arrastrar problemas previos
  • ●Menor tiempo de puesta en marcha

Particionado del disco

Gestión de particiones desde terminal

La orden lsblk muestra los dispositivos de bloque y sus particiones. Con fdisk se crean o eliminan particiones.

terminal — bash 
$ sudo lsblk
NAME   SIZE TYPE MOUNTPOINT
sda    500G disk
├─sda1 512M part /boot/efi
├─sda2  16G part [SWAP]
└─sda3 483G part /

$ sudo fdisk /dev/sdb
Command (m for help): n

Simulador

Planificación FIFO

Cambia llegada y ejecución y avanza el tiempo paso a paso. Respuesta = fin − llegada; espera = respuesta − ejecución.

Simulador

Planificación SRTF

Expulsivo: entra siempre el que menos tiempo tiene pendiente, aunque haya que desalojar al que está en la CPU. Si empatan, sigue el que está.

Simulador

Planificación SJF

No expulsivo: cuando la CPU queda libre entra el proceso de menor tiempo de ejecución de los que esperan. Si empatan, el que llegó antes.

Simulador

Prioridades no expulsivo

La prioridad 1 es la más alta. Cuando la CPU queda libre entra el de mayor prioridad de los que esperan; si empatan, el que llegó antes.

Simulador

Prioridades expulsivo

La prioridad 1 es la más alta. Si llega un proceso más prioritario que el que está en la CPU, lo desaloja. Si empatan, sigue el que está.

Simulador

Round Robin, quantum 2

Expulsivo: cada proceso usa la CPU como mucho un quantum y vuelve al final de la cola. Si en el mismo instante llega uno y otro agota su quantum, entra antes en la cola el que llega.
