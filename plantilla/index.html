3.1 Introducción

Funciones del sistema operativo

El sistema operativo es el conjunto de programas que gestiona los recursos del equipo y actúa de intermediario entre el hardware y las aplicaciones.

  • —Gestión del procesador y la memoria
  • —Gestión de dispositivos de entrada y salida
  • —Gestión del sistema de archivos
Imagen o esquema

Figura 3.1. Pie de imagen descriptivo.

Concepto clave

Partición

División lógica de un disco físico que el sistema operativo trata como una unidad de almacenamiento independiente. Cada partición puede tener su propio sistema de archivos.

Un mismo disco puede contener varias particiones con distintos sistemas operativos.

3.4 Tipos de instalación

Instalación limpia frente a actualización

Instalación limpia

  • ●Elimina todos los datos del disco
  • ●Sistema sin errores heredados
  • ●Requiere reinstalar aplicaciones

Actualización

  • ●Conserva archivos y programas
  • ●Puede arrastrar problemas previos
  • ●Menor tiempo de puesta en marcha

3.3 Terminal

Gestión de particiones desde terminal

La orden lsblk muestra los dispositivos de bloque y sus particiones. Con fdisk se crean o eliminan particiones.

terminal — bash 
$ sudo lsblk
NAME   SIZE TYPE MOUNTPOINT
sda    500G disk
├─sda1 512M part /boot/efi
├─sda2  16G part [SWAP]
└─sda3 483G part /

$ sudo fdisk /dev/sdb
Command (m for help): n

De decimal a binario

Divide entre 2 sucesivamente y lee los restos de abajo arriba. Pulsa Comprobar para corregir y Otro ejercicio para practicar con un número nuevo.

La solución muestra el proceso paso a paso, pero reinicia tu racha de aciertos.

Practica

De binario a decimal

Aplica el teorema fundamental de la numeración: suma las potencias de 2 de las posiciones que valen 1.

Practica

Suma en binario

En cada columna solo pueden darse estos casos. Se trabaja de derecha a izquierda.

SumoValeEscriboMe llevo
0 + 0000
0 + 1110
1 + 0110
1 + 12 = 1001
1 + 1 + 13 = 1111

La última fila es la de una columna que recibe un acarreo: el 1 que me llevaba se suma como un tercer sumando.

Practica

Resta en complemento a 2

Calcula el complemento a 2 del sustraendo, súmalo al minuendo y descarta el bit de acarreo que sobra.
